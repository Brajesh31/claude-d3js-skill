# Claude D3.js Skill

A Claude skill for building data visualisations with D3.js, from reusable chart structures to interactive visualisations.

## Repository contents

- `SKILL.md`: core skill instructions.
- `assets/`: chart and interactive templates, plus sample data.
- `references/`: D3 patterns, colour schemes, and scale guidance.

## Usage

Install this skill in the skills directory used by your Claude-compatible environment. Keep the `assets/` and `references/` directories alongside `SKILL.md`, since the skill references these supporting files.

Use it when creating D3.js charts, interactive data visualisations, or choosing scales and colour systems.
